EMR Camden fires — visualization bundle

Investigative-journalism map and chart set for the EMR Eastern scrap-metal recycling facility in Camden, NJ. Each file in this bundle is self-contained — open any HTML in a browser (needs internet for Leaflet + basemap tiles); open the PNGs in any image viewer.

All HTML maps require an internet connection to load Leaflet and CARTO basemap tiles. The data and JavaScript are inlined, so no other files need to travel with them. Cite OSM where used: "© OpenStreetMap contributors."
Two versions of each headline figure are included: files numbered 01/09/10 use the raw uncorrected PurpleAir ATM channel (what we originally pulled). Files suffixed with b use the EPA Barkjohn-corrected values (Barkjohn et al., Atmospheric Measurement Techniques 2021 — the formula AirNow's Fire and Smoke Map applies). For publication, prefer the corrected versions; keep the raw versions for transparency / methodology notes.
